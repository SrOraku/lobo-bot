# Áudios das autorespostas

Não há áudios de terceiros embutidos. Para cadastrar um áudio próprio, responda à mensagem de áudio com:

`!autoresposta add exact bom dia | audio`

O áudio é convertido para MP3 e guardado de modo privado em `storage/autorespostas/`. Essa mídia fica persistida porque o administrador pediu seu uso como resposta automática. Não inclua gravações privadas no Git. Vídeo, imagem e figurinha usam o mesmo cadastro com `video`, `image` ou `sticker`.
